Methodology

How The
Signal Works

Sentinel-1 C-band radar (5.6 GHz) images Kharg Island 2–3 times per week regardless of clouds, darkness, or weather. Floating-roof tanks cast measurable radar shadows — the geometry of that shadow reveals whether the roof is high (full) or low (near-empty).

We apply inverse crescent radiometry: a far-side mask on each tank extracts the VV backscatter signal, which is inverted and calibrated against a global 5th–95th percentile range updated with each pipeline run. Known tank dimensions (radius, max height per API 650) convert fill ratio to barrels.

The result is a physical inventory reading at the source — before any tanker moves, before any government reports, before AIS picks up a vessel departure.
